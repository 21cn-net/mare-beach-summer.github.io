## 🌊 About MARÉ

**MARÉ --- Beach & Summer** is a premium coastal lifestyle storefront
built around the feeling of long summer days, warm sand, ocean air, and
effortless travel.

The brand combines a fresh coastal identity with a carefully curated
selection of beach and summer essentials. The goal is to create an
online experience that feels closer to a modern resort boutique than a
conventional e-commerce catalog.

MARÉ focuses on products that are useful at the beach, pool, resort,
vacation destination, or during warm-weather travel while maintaining a
cohesive visual identity.

### Brand philosophy

> **Bring the coast closer.**

MARÉ is built around simplicity, sunshine, movement, and thoughtful
details.

------------------------------------------------------------------------

## ☀️ Brand Direction

MARÉ combines three core ideas:

**Coastal**\
Ocean-inspired colors, natural textures, beach environments, and relaxed
visual compositions.

**Refined**\
Clean typography, carefully selected products, generous spacing, and
premium presentation.

**Effortless**\
A shopping experience that feels simple, intuitive, and relaxed.

The result is a brand identity designed to feel fresh without becoming
overly tropical or visually crowded.

## 🌅 Photography Direction

Photography is one of the most important parts of the MARÉ experience.

Preferred imagery should feature:

-   Realistic product photography
-   Clean compositions
-   Natural daylight
-   Beach and resort environments
-   Ocean textures
-   Sand and natural materials
-   Poolside settings
-   Vacation lifestyle scenes
-   Carefully framed products

### Product photography principles

Every product should be:

-   Clearly visible
-   Properly framed
-   Centered when appropriate
-   Free from unrelated objects
-   Presented without website UI
-   Presented without prices embedded in images
-   Presented without buttons or promotional overlays
-   High enough quality for web use
-   Optimized for fast loading

Product images should never make the catalog feel like a collection of
screenshots.

## 🚀 GitHub Pages

MARÉ is designed to work with GitHub Pages as a static storefront.

### Basic deployment

1.  Create the GitHub repository.
2.  Upload the project files.
3.  Commit the changes.
4.  Open **Settings → Pages**.
5.  Select the publishing branch.
6.  Select the project root.
7.  Save the configuration.
8.  Wait for GitHub Pages to publish the site.

Before launch, confirm that all local assets and navigation routes work
correctly on the published domain.

Products and navigation should feel simple.
